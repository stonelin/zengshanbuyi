## 2. 5 轮多角色独立评审详细质询与重构矩阵

### 【第 1 轮】全局信息架构、用户旅程与新中式视觉规范

| 评审角色 | 独立质疑与核心痛点 (Critique) | 决策层权衡与重构对策 (Refined Solution) |
| :--- | :--- | :--- |
| **🎨 专业设计师** | 传统周易产品过度堆砌太极阴阳水墨背景，视觉噪音大，信息层级混乱；移动端双卦并列易造成重叠。 | **推行“新中式极简（Neo-Chinese Minimalist）”**：严禁低质祥云背景，确立宣纸白（`#FBF9F5`）与松烟墨（`#1F2421`）基调，移动端采用自适应折叠与滑动对比。 |
| **🌱 小白用户** | 一进首页就被“四卷目录、浑天甲子”等大量专有名词吓退，不知从何开始。 | **增设首页“30秒探索行动卡片”**（摇卦/看案/学第0阶），并提供全局**“小白友好模式”**，自动显示通俗注释。 |
| **📜 易学大师** | 现代排盘软件充斥大量伪神煞（如天乙/驿马/桃花），严重违背野鹤老人“删尽伪法、专重日月动变”的实战宗旨。 | **严格恪守野鹤宗风**：默认盘面完全剔除杂神煞，仅保留日月用神动变；分卷 100% 对应李文辉序定本四卷原构。 |

### 【第 2 轮】智能起卦排盘器与动态推演工作台

| 评审角色 | 独立质疑与核心痛点 (Critique) | 决策层权衡与重构对策 (Refined Solution) |
| :--- | :--- | :--- |
| **🎨 专业设计师** | 摇铜钱如果连续点击 6 次毫无动效反馈，用户无法感知当前摇的是哪一爻；盘面字段排布不齐。 | **增加 3D 物理翻转动效与步进器**（显示 `第 1/6 爻已就绪`），看板采用网格化胶囊对齐。 |
| **🌱 小白用户** | 铜钱正反面所代表的少阳/少阴/老阳/老阴完全分不清，老阳老阴为什么会变卦也看不懂。 | **在摇卦界面配备“即时图解卡片”**，并在变卦上方增加白话提示：“仅带 ◯ ✕ 的动爻会变，静爻不变”。 |
| **📜 易学大师** | 伏神查法常被错用，必须严格按八宫本宫纯卦查找；动爻的回头生克、化进化退是野鹤断卦绝技，必须显式标注。 | **算法严格绑定八宫纯卦映射**，点击伏神高亮飞神并提示生克；动变爻直接显示 `➯ 回头生` 或 `➯ 化退` 标签。 |

### 【第 3 轮】典籍沉浸式精读器与术语穿透体系

| 评审角色 | 独立质疑与核心痛点 (Critique) | 决策层权衡与重构对策 (Refined Solution) |
| :--- | :--- | :--- |
| **🎨 专业设计师** | 若全文到处都是术语高亮和下划线，会导致正文视觉破碎，严重破坏阅读心流。 | **采用灰点低饱和度下划线**，仅在 Hover 或开启“学习辅助”图层时凸显；浮窗引入智能视口避让算法。 |
| **🌱 小白用户** | 古籍文言文读不懂，只想查现代生活问题（如“我该不该换工作”），不知道对应哪一章。 | **每章配备“白话极简大意与一句话心法”**，并提供**“现代生活生活场景搜索指南”**（直达原著章节）。 |
| **📜 易学大师** | 野鹤老人的核心价值在于“辟前人之谬”，只看正文不知野鹤为何而战；《千金赋》为六爻宗经，需特殊处理。 | **设立“野鹤辟谬对比视窗”**（旧说 vs 野鹤实证）；为卷之二《千金赋》定制三栏赋文-野鹤原批-李增注特辑。 |

---

### 【第 4 轮】古籍实战卦例研习与“盲推探案”推演规范

| 评审角色 | 独立质疑与核心痛点 (Critique) | 决策层权衡与重构对策 (Refined Solution) |
| :--- | :--- | :--- |
| **🎨 专业设计师** | 必须做完 4 道选择题才能看答案对于想快速刷案例的高级研习者过于沉重；提交后页面跳动明显。 | **提供“探案模式”与“极速刷题模式”双切换**；采用 View Transitions API 保证展开平滑无跳动。 |
| **🌱 小白用户** | 盲推时要求推测“具体应期”太难，答错了直接给个大红叉极其挫败。 | **应期设为可选附加题并提供侦探线索提示**；反馈采用建设性鼓励（指出对了哪步、忽略了哪个法则）。 |
| **📜 易学大师** | 案例的精妙往往在于求占者的心理隐情与野鹤的精微辨析，不能只给出冷冰冰的吉凶选择题。 | **增加“野鹤断易精微点评”模块**，深度提炼人情世故与易理；每个案例明确标注原著卷次章节出处。 |

### 【第 5 轮】认知进阶树、闯关测试与评估复盘体系

| 评审角色 | 独立质疑与核心痛点 (Critique) | 决策层权衡与重构对策 (Refined Solution) |
| :--- | :--- | :--- |
| **🎨 专业设计师** | 常见技能树做成列表缺乏沉浸感与探索感；题目正误动效若过多会造成干扰。 | **构建“水墨山水卷轴进阶图”**，通关节点点亮篆刻印章；答题采用局部金色粒子微动效，结业才欢庆。 |
| **🌱 小白用户** | 错题后如果只给答案字母会很茫然；一次闯关失败如果必须重头开始会放弃。 | **错题解析实行“三段式闭环”**（错因 + 法则歌诀 + 直达原著出处章节）；支持错题单独重练重计分。 |
| **📜 易学大师** | 六爻各派断法争议极大，必须明确题目的唯一判准；必须考核辨别伪神煞的能力。 | **所有题目一律标明“（依据野鹤老人《增删卜易》定则）”**；在 Stage 2/3 增设“辟伪辨谬考题集”。 |
